    About

    SDET with 8 years of web and mobile test automation.

    I created Mobium, open-source mobile app automation for AI agents and humans. One Go binary drives Android and iOS apps on emulators, simulators and real phones, through a CLI, an MCP server and client libraries. I built its LLM evals:

    • a RAG quality gate over 82 reviewed questions
    • an LLM-as-judge study of agreement with human labels against run-to-run stability
    • agent evals with prompt A/B tests and prompt-injection red-team tasks

    I contribute code to Vibium, “the verification layer for coding agents”: 4 merged PRs, 50+ root-caused issues filed, and regression suites for its clients, CLI and MCP server.

    How it’s built

    Each suite runs from one script and, where it can, one Docker image, whichever CI calls it. Every run writes Allure results and a small status file, and GitHub Actions gathers them into the reports and this page.

    1. 1 · Source One repo, five run scripts ci/run-<suite>.sh, plus a demo web app the web suites test
    2. 2 · Images Docker images on GHCR built on every push to main; Compose and kind use the same images
    3. 3 · Five CIs
      • 4 · Reports Allure, with history one report per suite; trends kept across runs
      • 5 · Publish GitHub Pages this page reads each suite’s status JSON

      Live test suites

      Every suite runs on each push to main, nightly, and on demand. Run test suite opens that suite’s latest Allure report. Only the repository owner can start a new run, from the “Re-run” link.
